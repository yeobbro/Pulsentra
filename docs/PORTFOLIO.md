# Pulsentra — 프로젝트 기술 설명 (포트폴리오용)

> 이 문서는 검증된 사실만 적습니다(갱신 2026-10-25). Pulsentra는 수익을 낸 전략을 보유하고 있지 않습니다. 시장 대비 지속 가능한 우위(Alpha)를 입증한 전략도 없습니다. 실제 투자나 사업 성과도 없습니다.

## 한 줄 요약

한국 주식 일봉(2016–2026, 상장폐지 종목 포함 2,823종목, 약 580만 봉)으로 거래 전략을 검증하는 Python 리서치 시스템입니다. 데이터 품질 감사, 재현 가능한 실행 기록, 과적합과 편향 통제를 중심으로 설계했습니다.

## 기술적으로 한 일

- **데이터 품질 감사:** 종목·날짜 단위로 이상을 찾고, 원인 가설을 붙여 분류합니다. 예: "가격은 수정됐지만 거래량은 미수정된 10:1 분할", "가격제한폭을 넘는 연속 거래일 변동". 판정과 수정을 분리하고, 자동 보정은 전후 값으로 추적합니다. 감사와 백테스트가 정확히 같은 행을 보는지 테스트로 보장합니다.
- **재현성:** 실행마다 전체 커밋과 미커밋 파일, 패키지 버전, 난수 시드, 비용 가정 변경, 경고, 모든 산출물의 SHA-256을 기록합니다. 같은 입력으로 두 번 실행하면 결과 파일 해시가 같다는 것을 테스트합니다.
- **편향 통제:**
  - 기간 분리와 embargo, 기간 경계를 넘는 거래 계수
  - 무작위 진입 기준 분포, 월 군집 부트스트랩 신뢰구간
  - 시험한 조합 수 기록, 상장폐지 종목 포함
  - 신호 단위 통계에서 빠지는 상장폐지 거래 계수
- **외부 API 어댑터:**
  - 재시도 상한, 타임아웃, 스키마 검증
  - 읽기 전용 경로 허용 목록(KIS 주문 경로는 호출 불가)
  - 오류 메시지에 키가 들어가지 않도록 처리
- **교차 검증 설계:** 두 출처의 차이를 "누락", "수정 기준 차이(구간별 일정 비율)", "레코드 오류"로 나누는 비교 로직, 기업행동 후보와 공시의 매칭(원 공시와 정정 공시를 하나의 기업행동으로 묶음).
- **실제 데이터 적용(2026-10-24~25):**
  - 600만 행 데이터 감사를 두 번 실행해 산출물 지문이 같음을 확인
  - v0.3.0 코드와 v0.4 코드(`2edfc8b`)가 같은 실제 데이터에서 같은 결과를 냄을 확인
  - 저장된 KRX OPEN API 응답과 4개 거래일 전체 시장 대조(2025년 두 날짜 86~88% 완전 일치, 나머지는 대부분 수정주가 기준 차이. 2026-10-22·23은 원인 미확정)
  - OpenDART로 삼성전자 2018년 50:1 분할을 공시 원문에서 확인(1건)
- **라이선스 통제:** KRX OPEN API 약관(제3자 제공 금지)에 맞춰, KRX 응답이 앱 저장소에 들어가지 못하게 코드에서 막고 테스트로 보장합니다.
- **엔지니어링:**
  - pytest 272개 통과·2개 건너뜀(2026-10-25. 합성·TEST 데이터와 모의 API만 사용, 실제 API 테스트는 키가 있을 때만)
  - Python 3.11–3.13 CI, 의존성 잠금
  - pandas·NumPy 비호환 경고 173건을 원인 수정으로 제거

## 연구 결과 (부정적 결과 포함)

- 거래비용(왕복 약 0.43%)을 차감하면, 검증한 전략 5개 × 청산 규칙 48개 중 validation과 test 기간 모두에서 이익인 조합은 없었습니다(v0.3). 2026-10-24에 같은 실제 데이터로 다시 실행해 같은 결과를 확인했습니다(감사 결과 반영 전).
- 한 전략은 개발 구간에서만 무작위 진입 1,000회를 모두 이겼고, 이후 구간에서는 무작위보다 나빴습니다. 과적합으로 판단해 기각했습니다.
- ML 필터 15개 비교는 모두 채택 게이트를 통과하지 못했습니다.

## 한계 (숨기지 않는 것)

- 가격 데이터는 비공식 단일 출처입니다. 공식 출처 대조는 KRX 4개 거래일과 OpenDART 1건만 실행했고, KIS 가격 대조와 나머지 기업행동 후보 8,072건의 공시 대조는 하지 않았습니다. 네이버·KRX 데이터를 외부에 제공할 권한은 확인되지 않았습니다.
- 배당은 반영하지 않았습니다(가격 수익률). 무정지 무상증자는 탐지하기 어렵습니다. 세율은 단일 가정값입니다.
- v0.3 결과를 만든 원래 실행 커밋(`4918af9`)이 이력에서 사라져, 원래 실행 코드와의 동일성은 증명하지 못했습니다. v0.3.0 커밋(`a57dcc1`)으로 같은 실제 데이터를 다시 실행하면 전략 표가 같은 보고서가 나온다는 것(출력 재현)까지만 확인했습니다.
- 데이터 감사는 이상을 찾아 분류한 것이며, 검토 필요로 분류된 2,225종목을 검토하거나 감사 결과를 반영해 전략을 다시 검증하지는 않았습니다.
