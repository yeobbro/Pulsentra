## 1. 결론 요약

1. **거래비용을 뺀 뒤 validation과 test 두 기간 모두에서 우위가 확인된 전략은 없습니다.**
   - 전략 4개(A, B1, B2, C)와 단순 모멘텀 기준에, 청산 규칙 48개 조합을 모두 적용해 봤습니다.
   - validation과 test에서 거래당 평균 순수익이 0보다 큰 조합은 하나도 없었습니다(5 × 48 × 2 = 480개 중 0개).
2. **A(거래량 급증 + 횡보)는 개발 기간(dev)에만 좋아 보였습니다.**
   - dev에서는 거래당 +0.63%로 무작위 진입 1,000회를 모두 이겼습니다. 청산 조합 48개 중 35개가 양(+)이었습니다.
   - 같은 규칙을 validation(−0.93%)과 test(−0.83%)에 적용하자 무작위보다 나빴습니다(단측 p = 0.92, 1.00).
   - 포트폴리오 결과도 같은 흐름입니다. dev +133.8%(KOSPI +55.2%), validation −6.1%(KOSPI −11.2%), test −18.0%(KOSPI +107.9%).
   - 이는 개발 구간에 과적합된 결과로 해석합니다.
3. **B1, B2, C는 세 기간 모두 손실이었고, 대부분 무작위 진입보다도 나빴습니다.** dev 기간 48개 조합 중 신뢰구간이 0 아래에 있는 경우도 많았습니다(B1 45개, B2 42개, C 30개).
4. **단순 모멘텀(120일 종가 신고가)은 기간마다 결과가 엇갈렸습니다.** test에서는 무작위 진입보다 나았지만(p < 0.001), 거래당 평균은 여전히 −0.05%였습니다.
5. **ML 필터는 채택하지 않았습니다.** 15개 모델 비교(5개 전략 × 3개 모델) 중 validation 채택 기준을 통과한 것은 없었습니다. validation 기준 AUC는 0.45~0.59, Brier skill은 −0.008~+0.005였습니다(test: AUC 0.47~0.59, Brier skill −0.008~+0.009).
6. **무작위 진입도 기간과 무관하게 거래당 −0.14~−0.82%였습니다.** 이번 표본(10억 원 이상 유동성, 종가 1,000원 이상)에서 짧은 스윙 거래는 비용(왕복 약 0.43%)을 넘기기 어려웠습니다.
   - test 기간 KOSPI가 +108% 오른 것은 시가총액 상위 종목 영향입니다. 같은 기간 KOSDAQ 지수는 −14.5%였습니다.
   - 반면 거래 단위 결과는 종목을 동일 가중으로 본 것이고, 표본의 68%가 KOSDAQ 종목입니다(2,823개 중 1,919개).

이 결론은 아래 데이터, 비용 가정, 체결 규칙에서만 성립합니다. 전략 아이디어 자체를 기각하는 근거로 일반화하지 않습니다. 다만 현재 정의 그대로는 운영 신호로 쓸 근거가 없습니다.

## 3. 방법

- **체결:**
  - 신호는 t일 종가로 판단하고, t+1일 시가에 슬리피지 10bp를 더해 진입합니다.
  - 같은 봉에서 손절가와 익절가를 모두 지나면 손절로 처리합니다. 분봉이 없어 순서를 알 수 없기 때문입니다.
  - 갭은 시가에 체결합니다. 거래정지 뒤 첫 거래일에 손절가 아래로 열리면 그 시가에 손절합니다.
  - 비용은 편도 수수료 1.5bp, 매도세 20bp, 매도 슬리피지 10bp입니다. 모두 가정값입니다.
- **적격 조건 (모든 전략·기준 공통):**
  - 20일 평균 추정 거래대금 10억 원 이상, 종가 1,000원 이상
  - ATR 계산 가능
  - 거래량 창이 분할·병합 의심 구간에 걸리지 않음
- **청산 조합 48개:**
  - 손절: ATR 1.5, ATR 2.0, 고정 7%, 10일 스윙 저점
  - 익절: 1.5R, 2R, 3R, 1.5R에서 절반 익절 후 ATR 2배 추적 손절
  - 보유 기간: 5, 10, 20거래일
  - 같은 진입 신호에 독립적으로 적용합니다(거래 단위).
- **기간과 선택 규칙:**
  - dev 2016~2021, validation 2022~2023, test 2024~2026-10으로 나눴습니다. 각 기간 끝 35일 이내의 신호는 제외해, 다음 기간 데이터로 청산되는 일이 없게 했습니다.
  - 전략별로 dev 거래당 평균 순수익이 가장 높은 조합을 하나 고르고, 그 조합을 validation·test에 그대로 적용했습니다.
  - 48개 조합 전체 결과는 `strategy_exit_grid.csv`에 보존했습니다.
- **추가 검증:**
  - 연도별 워크포워드: 매년 그 이전 데이터로만 청산 규칙을 다시 고릅니다.
  - 무작위 진입 비교: 같은 기간, 같은 청산 규칙으로 같은 거래 수를 1,000회 추출합니다.
  - 국면별 분석: KOSPI 60일 수익률 ±5% 기준으로 상승·하락·횡보를 나눕니다.
  - 비용 민감도: 비용 0, 기본, 슬리피지 3배.
  - 포트폴리오 백테스트: 자금 1억 원, 거래당 위험 0.5%, 10종목, 낙폭 25%에서 20영업일 진입 중단.
- **신뢰구간:** 같은 달의 신호는 서로 상관되므로, 신호 월 단위로 묶어 재표본추출하는 군집 부트스트랩(2,000회)으로 계산했습니다.
- **다중 비교:** 전략 5개 × 조합 48개 = 240개 설정을 dev에서 비교했습니다. 그래서 dev에서 '가장 좋은' 결과는 과대평가되기 쉽고, 판단은 validation·test로 합니다.
- **ML:**
  - 라벨은 ATR 1.5 손절, 2R 익절, 10일 기준으로 익절이 손절보다 먼저 일어났는지입니다.
  - dev로 학습하고, dev 마지막 20%로 확률을 보정했습니다.
  - validation에서 채택 여부를 판정했습니다. 기준은 AUC 0.55 이상, Brier skill 0 초과, 선택 거래 30건 이상, 선택 거래 순수익의 95% 신뢰구간 하한 0 초과, 규칙 전체보다 우수입니다.
  - test는 최종 보고용으로만 썼습니다.

## 6. 검증하지 못했거나 남은 한계

- **가격 출처:** 공식 API가 아닌 단일 출처입니다. 다른 출처(KRX 로그인, KIS)와 대조하지 못했습니다.
- **현금 배당:** 반영하지 않았습니다(가격 수익률). 장기 보유 기준과 비교할 때 불리하게 작용합니다.
- **기업행동:** 무상증자처럼 거래정지가 없는 이벤트의 거래량 불연속은 탐지하지 못합니다. 공시(OpenDART)로 대조하지도 않았습니다.
- **거래대금:** 추정값입니다. 분할 전 구간에서는 실제보다 작게 추정됩니다.
- **상장폐지:** 폐지 목록 자체가 완전한지 확인하지 못했습니다. 폐지 당일 정리매매 가격이 실제 매도 가능 가격과 다를 수 있습니다.
- **체결 비용:** 분봉이 없어 장중 체결 순서를 알 수 없습니다(보수적 가정). 시장 충격과 호가 단위는 모형화하지 않았습니다.
- **세율:** 매도세 20bp는 단일 가정값입니다. 연도·시장별 실제 세율과 다를 수 있습니다.
- **기간 분리:** 기간 경계를 한 가지(2021/2023)로만 시험했습니다.
- **ML 범위:** 라벨 한 종류, 특징 세트 한 종류만 시험했습니다.

## 7. 다음 단계 권고

1. **데이터 교차 검증:** KRX 계정이나 KIS 키로 공식 출처를 확보해, 네이버 일봉과 표본 대조(종가·거래량)합니다. OpenDART 키로 분할·병합·무상증자를 공시와 맞춰 봅니다.
2. **배당 반영:** 총수익 지수와 배당 데이터를 확보한 뒤 장기 기준선과 다시 비교합니다.
3. **가설 수정은 사전 등록 방식으로:** 새 조건을 dev에서 찾았다면 validation·test는 한 번만 열어 봅니다. 이번 test 기간은 이미 사용했으므로, 앞으로 쌓이는 2026-11 이후 데이터를 새 test 기간으로 남겨 두는 것을 권장합니다.
4. **보유 기간과 비용 구조:** 짧은 스윙이 비용을 넘지 못했으므로, 비용 대비 기대 이동폭이 큰 조건(변동성·유동성 구간별)을 별도 가설로 검증합니다.
5. **모의투자는 운영 신호가 아니라 추적 용도로만:** 현재 어떤 전략도 실전 신호 근거가 없습니다.
