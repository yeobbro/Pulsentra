# 데이터 출처와 출처 유형 (v0.3)

## 출처 유형 (`candles.source_type`)

| 유형 | 의미 | 출처 예시 |
|---|---|---|
| `REAL` | 실제 시장 데이터 | `csv_import`, `kis_eod`, `naver_fchart` |
| `SYNTHETIC` | 합성 데이터 (화면·개발용) | `synthetic_demo` (화면 상태는 DEMO로 표시) |
| `TEST` | 자동 테스트 픽스처 | `test` |

- 한 종목 시계열에 REAL과 다른 유형을 함께 저장하면 적재 단계에서 거부합니다 (`app/data/ingest.py`).
- 리서치 실행(`python -m app.research`)은 REAL 이외 데이터가 하나라도 있으면 중단합니다.

## v0.3 실데이터 수집 경로 (`scripts/collect_kr_daily.py`)

| 데이터 | 출처 | 공식 API 여부 | 확인된 특성 |
|---|---|---|---|
| 종목별 일봉 OHLCV | 네이버 금융 차트 `fchart.stock.naver.com/sise.nhn` | **아님** — 인증 없는 웹 차트 엔드포인트. 문서·약관상 보장 없음 | 가격은 수정주가(삼성전자 2018-05-04 50:1 분할 전후 가격 연속 확인). **거래량은 수정되지 않음**(분할 전 거래량이 약 1/50). 거래 정지일은 시가·고가·저가 0, 거래량 0 행으로 표시. 거래대금 없음 |
| 현재 상장 목록 | FinanceDataReader `StockListing('KRX')` → FinanceData 프로젝트가 GitHub에 캐시한 KRX 목록 스냅샷 | 아님 (제3자 캐시) | 수집 시점 기준 목록 |
| 상장폐지 목록 | FinanceDataReader `StockListing('KRX-DELISTING')` → GitHub 캐시 | 아님 (제3자 캐시) | 폐지일·사유 포함. 목록 누락 여부는 확인하지 못함 |
| KOSPI·KOSDAQ 지수 | FinanceDataReader `DataReader('KS11'/'KQ11')` → GitHub에 캐시된 KRX 지수 이력 | 아님 (제3자 캐시) | 가격지수(배당 미포함) |

모든 요청 URL, 수집 시각(UTC), 행 수, 파일 SHA-256은 `data/real/manifest.jsonl`에 기록됩니다.

### 확인했지만 쓰지 못한 공식 경로
- **KRX 정보데이터시스템**(`data.krx.co.kr`): 2026-10 현재 로그인(KRX_ID/KRX_PW)이 필요해 이번 환경에서 호출하지 못했습니다(`pykrx 1.2.9`가 로그인 실패 메시지 출력, 빈 결과).
- **한국투자증권 Open API**: 키가 없어 호출하지 않았습니다. 어댑터 코드(`app/providers/kis.py`)는 그대로 있습니다.
- **OpenDART**: 키가 없어 호출하지 않았습니다. 그래서 액면분할·병합·무상증자 같은 기업행동을 공시로 대조하지 못했습니다.

## 이용 조건
수집한 원자료는 개인 연구용으로 로컬에만 보관합니다. 재배포나 상업적 이용 전에는 각 제공자(네이버, KRX, FinanceData 프로젝트)의 이용 약관을 확인해야 합니다. `data/real/`은 `.gitignore`에 포함되어 있습니다.

## 데이터 처리 규칙 (리서치 로더 `app/research/data.py`)
1. **거래 정지 표시 행**(시가=고가=저가=0): 일봉이 아니므로 제거하고 `provider_halt_rows.csv`에 기록합니다.
2. **수정주가 반올림 오차**: 종가가 고가보다 1원 큰 것처럼 상대 0.2% 이내로 어긋난 행은 고가·저가를 넓혀 보정합니다. 보정한 행에는 `ohlc_rounding_repaired` 플래그를 남깁니다. 그보다 크게 어긋나면 오류로 제외합니다.
3. **거래량 미수정 분할·병합**: 거래 정지 공백을 사이에 두고 60거래일 중앙 거래량이 3배 이상 변하면 `volume_level_break`로 표시합니다. 그 지점을 포함하는 40거래일 거래량 창의 신호는 모든 전략에서 제외합니다(무작위 기준 포함).
4. **거래대금**: `수정종가 × 거래량`으로 추정합니다. 유동성 필터에만 쓰며, 분할 전 구간에서는 실제보다 작게 추정됩니다(보수적).
5. **현금 배당**: 반영하지 않습니다. 모든 수익률은 배당을 뺀 가격 수익률입니다.
6. **탐지하지 못하는 것**: 거래 정지 없이 일어난 무상증자 등의 거래량 불연속.
