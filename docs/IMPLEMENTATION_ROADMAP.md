## v0.4 — 데이터 감사·재현성 (진행 중)
- ✅ 종목 단위 감사(원인 분류·보정 전후·제외 구간·기업행동 후보), 로더와 행 일치 (`docs/DATA_AUDIT.md`)
- ✅ manifest v2, 의존성 잠금, CI, 결과 상태 판정, 기간 경계·미청산 거래 계수
- ✅ 어댑터 재시도 상한·스키마 검증·읽기 전용 경로, 교차 검증 로직과 실행기
- 🟡 실제 데이터 감사 실행 (데이터가 있는 환경 필요)
- ⬜ KIS·OpenDART 실제 대조 실행 (키 필요), 배당 반영, 연도별 세율, 상장폐지 목록 참조 대조

## v0.3 — 실데이터 검증
- ✅ 실데이터 수집기·출처 유형·기업행동 점검·리서치 파이프라인·보고서 (`docs/RESEARCH_V0_3.md`)
- ⬜ 공식 출처(KRX·KIS·OpenDART) 교차 검증, 배당 반영

## Phase 1 — 신뢰할 수 있는 데이터와 백테스트
- ✅ 기존 MVP 조사 (`docs/MVP_ANALYSIS.md`)
- ✅ 데이터 표준(수정주가 여부·출처·수집 시각·품질 플래그), 데이터 상태 6종
- ✅ 품질 검사: 중복·결측·비정상 가격·고저 역전·음수 거래량·급변·분할 의심·거래일 누락·거래량 0·수집 실패·오래된 데이터
- ✅ CSV 적재(행 단위 검증, 수집 기록), 종목 메타데이터(상장·폐지·업종·벤치마크)
- ✅ 거래비용·세금·슬리피지, 다음 날 시가 체결, 같은 봉 손절 우선
- ✅ 거래량 급증 스캐너, 손절·익절 비교, 기본 리포트
- 🟡 기업행동: 수정주가 여부 기록 + 분할 의심 경고 (자동 조정 없음)
- 🟡 생존편향: 상장폐지 메타데이터·청산 처리 지원, 실제 폐지 종목 데이터는 사용자가 적재해야 함

## Phase 2 — 전략 비교
- ✅ 전략 플러그인 10종 (공시 이벤트 전략은 미구현으로 표시)
- ✅ 벤치마크(지수 또는 동일가중 대용), 무작위 진입 기준 분포
- ✅ 워크포워드 파라미터 선택, 월별·연도별, 국면별, 신뢰구간·표본 경고

## Phase 3 — 머신러닝
- ✅ 기준(기준 확률·단순 규칙), 로지스틱, 랜덤포레스트, HistGradientBoosting
- ✅ 퍼지된 시간순 워크포워드, 학습 구간 내 확률 보정, 누수 검사
- ✅ 규칙 vs ML 필터 비교(표본 외 예측만), 모델 기록, 채택 게이트
- ⬜ LightGBM, LSTM, 시점 정보가 있는 재무 특징
- ✅ 실데이터 검증 (v0.3): ML 필터 15개 비교 모두 불채택

## Phase 4 — 실시간
- 🟡 틱→1·5분봉 집계, 수신 지연 판정
- ⬜ KIS WebSocket, 분봉 저장, 장중 신호
- 🟡 알림: 종가 기준 규칙·중복 방지·입력값 저장 (외부 발송 없음)

## Phase 5 — 모의투자·서비스
- ✅ 가상 계좌·주문(시장가/지정가·만료·거부)·청산·백테스트 비교
- ⬜ 일별 자동 처리 스케줄러, 사용자 계정, 운영 모니터링
- ⬜ 실제 주문 (범위 밖. 별도 승인, 보안·규제 검토 필요)
