    처음 사용하는 경우

    1. 데이터 센터에서 실제 일봉 CSV를 올리거나(HISTORICAL), KIS 키를 설정해 국내 일봉을 동기화합니다(DELAYED). 화면만 보려면 DEMO를 불러옵니다.
    2. 시장지수(벤치마크)와 종목 메타데이터(업종·상장/폐지일)를 함께 올리면 상대강도·국면 분석·생존편향 점검이 가능해집니다.
    3. Market Scanner → 종목 상세 → Strategy Lab에서 가설을 검증하고, 워크포워드·무작위 진입 기준과 비교합니다.
    4. ML Lab은 단순 규칙보다 나은지 표본 외로 검증합니다. 채택 기준을 통과하지 못하면 예측을 제공하지 않습니다.
